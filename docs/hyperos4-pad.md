# Xiaomi Pad 9 Pro Max 适配说明

本项目基于 Xiaomi Pad 9 Pro Max（代号 `yingtian`）官方全量包 **OS4.0.15.0.XBMCNXM / Android 17** 移植，拥有独立的 `pad-v*` 版本线，与手机版及 OS3 镜像相互独立。

## 规格与默认配置

| 项目 | 参数配置 |
| --- | --- |
| 默认实例名 / 端口 | `HyperOS_4_Pad9ProMax_API_37` / `emulator-5582` |
| 工作目录 | `work/os4-pad` |
| 移植底包 | Android 17 / HyperOS `OS4.0.15.0.XBMCNXM` |
| 原厂机型标识 | `yingtian` / `M367FC` / Xiaomi Pad 9 Pro Max |
| 屏幕显示 | 横屏 `3408×2272`，逻辑密度 `400 dpi` |
| 推荐资源配置 | 4 核 CPU / 4 GiB 内存 / 32 GiB 存储（均可在安装或管理菜单中调大） |
| 机型特性 | 搭载官方 `yingtian.xml` 配置；原机不支持的 AOD 息屏显示保持关闭 |

### 快速启动与构建

日常使用推荐使用项目启动脚本（或安装器的“启动实例”菜单）：

```sh
./Start-HyperOS4-Pad.command
```

如需从官方 OTA 重新构建系统镜像（需要准备好 API 36 ARM64 底包与构建依赖）：

```sh
python3 scripts/build_os4_pad.py --weather-angle-libs /path/to/verified-angle-libs
```

## 核心适配技术说明

### 1. 横屏显示与 macOS 色彩管理
- **横屏输出**：真机物理面板为 `2272×3408` 竖向安装。模拟器保留此物理尺寸，由 Android WindowManager 以 270° 方向输出 `3408×2272` 横屏画面，启动脚本会自动调整 macOS 窗口方向为正向显示。
- **色彩校准**：启动脚本会自动为 macOS 模拟器窗口与 Metal 渲染层配置 **sRGB 色彩空间标记**，并锁定 Android 自然色彩模式（饱和度 1.0），消除了画面偏艳与色彩过饱和现象。
- **60 Hz 刷新率锁定**：系统配置与启动服务将 SurfaceFlinger 实际渲染帧率与面板刷新率均锁定为稳定的 60 Hz，滑动与操作更加流畅。

### 2. 硬件加速（HWUI）与 Vulkan 渲染
- **Skia-Vulkan 渲染**：平板默认启用 `skiavk` 硬件加速，并应用底层单指令补丁跳过 Zygote 阶段的 GPU 驱动预加载，同时完整保留小米官方的着色器预加载与模糊混合组件。
- **材质与弹窗修复**：控制中心、设置及官方天气的背景高斯模糊与玻璃材质均正常渲染；在 Vulkan 渲染模式下，天气定位权限等系统弹窗可正常以不透明背景与完整尺寸入场，消除了 OpenGL 模式下弹窗背景透出且尺寸缩小的显示缺陷。
- **稳定性保护**：平板启动器单独开启了 `-feature VulkanBatchedDescriptorSetUpdate` 特性，规避了部分 MoltenVK 路径下的宿主崩溃风险。

### 3. 系统应用与视觉特性
- **小爱同学光效**：平板预装小爱组件内置 MGL2 原生渲染引擎。项目补丁针对模拟器 OpenGL ES 环境调整了着色器版本声明与 EGL 透明通道，长按电源键唤出时光效正常渐入渐出，桌面背景保持透明可见。
- **平板官方相机**：为平板原装相机提供了专用 ANGLE 配置与原生 JNI 桥接，前后置摄像头均支持画面预览、镜头切换与基础拍照功能。
- **天气渲染**：适配了平板专属的 Flutter 引擎与 ANGLE 桥接，支持城市搜索、天气预报文字与动态天气背景渲染。
- **开机引导与常亮**：禁用了在模拟器环境下缺少硬件安全芯片支持的查找设备状态查询，全新安装可顺利通过官方首次开机向导；系统资源与启动器配置了永不休眠，避免长时间无操作黑屏。

## 已知限制与注意事项

1. **相机功能**：当前主要支持虚拟场景下的基础画面预览与标准拍照；高级夜景、人像虚化、多倍变焦及高质量视频录制等计算摄影特性暂未完整支持。
2. **云服务与外设**：蓝牙功能、小米云服务、Google 登录及 Play 完整性认证（Play Integrity）暂未适配。
3. **宿主退出**：在部分 macOS 环境下，虚拟机内点击关机后，宿主模拟器进程可能不会自动退出，此时手动关闭模拟器窗口即可。
4. **资源分配**：默认的 4 GiB 内存为起步配置，若宿主 Mac 内存充裕（如 16 GiB 或以上），建议通过安装器菜单调整至 6 GiB 或 8 GiB，体验更佳。
