# HyperOS 4.0.24.0 · v0.2.5 · Apple Silicon · r6.2

Release Tag：`v0.2.5-a17-hyperos4-hongkong-r6.2`。本次为同底包增量更新，继续使用小米 18 Pro（hongkong）官方 **OS4.0.24.0.XFRCNXM / Android 17**。

## 本次更新

- 支持 Magic Trackpad 和 Mac 内置触控板的双指上下滚动、左右滑动切页。双指滑动转换为连续触摸，方向遵循 macOS 设置，松手后由 Android 处理惯性。
- 触控板适配同时支持主屏和独立背屏窗口，启动器已附带预编译文件，无需自行编译。源码启动可用 `--no-host-trackpad` 临时关闭此功能。
- 加入系统 MediaCodec 的 AC-3 / E-AC-3 解码支持，应用可直接使用系统解码器播放立体声及 5.1 声道音源。5.1 输出会下混为立体声。
- 更新至 **Core 20 / Apps 8**，兼容规则继续按实际文件、ARM64 架构与硬件能力匹配。
- 保留 r6.1 的窗口旋转、背屏触控区域及旧启动设置迁移修复。

E-AC-3 JOC 与 AC-4 目前仅完成解码器注册，完整 Atmos 播放不在本次支持范围内。

## 安装与升级

需要 **Installer 1.3.1 或更新版本**。关闭目标 AVD，在安装器中选择 r6.2 即可。

| 当前版本 | 直接使用的增量 |
| --- | --- |
| r6（r6.0） | r6 → r6.2 |
| r6.1 | r6.1 → r6.2 |

安装器优先复用当前版本的完整发行文件，只下载对应增量，无需重新下载 r6 完整包。首次安装或缺少可用源文件时，安装器自动获取 r6 完整包和 r6 → r6.2 增量，直接还原并安装 r6.2，无需安装或启动 r6、r6.1。

升级前会备份应用数据、磁盘覆盖层、加密密钥与配置。请保留实例目录内的 `versions` 文件夹，安装器需要其中的发行文件来还原增量。

本 Release 提供两条直达增量的全部分卷、`manifest.json` 和 `SHA256SUMS`。原 r6 完整包及 r6.1 附件继续保留。离线升级只需目标清单与当前版本对应的增量，首次离线安装还需 r6 完整包，详见[安装指南](https://github.com/NEORUAA/HyperOS-AVD/blob/main/docs/installing.md)。

相机高级算法、蓝牙、小米云服务与 Google 服务的兼容范围沿用 r6。
