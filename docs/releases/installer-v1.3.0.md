# HyperOS-AVD Installer v1.3.0

Release Tag：`installer-v1.3.0`。

- 支持 **r6.1 / r3.1 等仅增量修复版**，复用本地完整包，只下载修复内容。
- 新用户可直接选择修复版，安装器自动下载并校验所需完整包，然后还原并安装目标版本，无需先手动安装旧版。
- 支持同底包的文件与数据块差分、断点续传和离线安装。
- 按数字比较 `r6`、`r6.1`、`r6.2` 等修订号，防止保数据降级。
- 沿用升级前备份、配置保留与恢复流程，继续支持已有 OS3、Phone 和 Pad 完整发行包。

仅增量修复版需要本安装器或更新版本。原有完整运行包仍沿用 Installer 1.2.3 的协议基线。

安装器附件包含 `Installer ZIP`、`install.sh`、`installer.json` 与 `SHA256SUMS`。操作说明见[安装、升级与恢复指南](../installing.md)。
