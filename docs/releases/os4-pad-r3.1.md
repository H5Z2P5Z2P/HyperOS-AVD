# HyperOS Pad 4.0.15.0 · v0.1.2 · Apple Silicon · r3.1

Release Tag：`pad-v0.1.2-a17-hyperos4-yingtian-r3.1`。这是基于 Pad r3 的仅增量修复版，继续使用 Xiaomi Pad 9 Pro Max（yingtian）官方 **OS4.0.15.0.XBMCNXM / Android 17**。

## 本次修复

- 更新宿主机窗口旋转处理，按当前显示方向调整窗口尺寸。
- 更新至 **Core 19 / Apps 8**，按实际文件、ARM64 架构与硬件能力匹配兼容规则。
- 清理已由新版兼容模块接管的旧全局启动设置，保留原有迁移备份。
- 沿用平板独立的横屏显示、渲染与设备配置。

## 安装与升级

需要 **Installer 1.3.1 或更新版本**。关闭目标 AVD，在安装器中选择 r3.1 即可。

已有完整 r3 文件时，只下载本次修复包。首次安装或缺少 r3 文件时，安装器会自动下载 r3 完整包，再应用修复并直接安装 r3.1。升级前仍会备份应用数据、磁盘覆盖层、加密密钥与配置。

本 Release 只提供增量分卷、`manifest.json` 和 `SHA256SUMS`。离线安装需同时准备 Pad r3 完整包，具体目录结构见[安装指南](../installing.md)。手机与平板修复包不能混用。

相机高级算法、蓝牙、小米云服务与 Google 服务的兼容范围沿用 r3。
