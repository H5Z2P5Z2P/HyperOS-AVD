# HyperOS Pad 4.0.15.0 · v0.1.2 · Apple Silicon · r3.2

Release Tag：`pad-v0.1.2-a17-hyperos4-yingtian-r3.2`。本次为同底包增量更新，继续使用 Xiaomi Pad 9 Pro Max（yingtian）官方 **OS4.0.15.0.XBMCNXM / Android 17**。

## 本次更新

- 支持 Magic Trackpad 和 Mac 内置触控板的双指上下滚动、左右滑动切页。双指滑动转换为连续触摸，方向遵循 macOS 设置，松手后由 Android 处理惯性。
- 启动器已附带预编译触控板适配，无需自行编译。源码启动可用 `--no-host-trackpad` 临时关闭此功能。
- 更新至 **Core 20 / Apps 8**，兼容规则继续按实际文件、ARM64 架构与硬件能力匹配。
- 保留 r3.1 的窗口旋转与旧启动设置迁移修复，沿用平板独立的横屏显示、渲染及设备配置。

## 安装与升级

需要 **Installer 1.3.1 或更新版本**。关闭目标 AVD，在安装器中选择 r3.2 即可。

| 当前版本 | 直接使用的增量 |
| --- | --- |
| r3（r3.0） | r3 → r3.2 |
| r3.1 | r3.1 → r3.2 |

安装器优先复用当前版本的完整发行文件，只下载对应增量，无需重新下载 r3 完整包。首次安装或缺少可用源文件时，安装器自动获取 r3 完整包和 r3 → r3.2 增量，直接还原并安装 r3.2，无需安装或启动 r3、r3.1。

升级前会备份应用数据、磁盘覆盖层、加密密钥与配置。请保留实例目录内的 `versions` 文件夹，安装器需要其中的发行文件来还原增量。

本 Release 提供两条直达增量的全部分卷、`manifest.json` 和 `SHA256SUMS`。原 r3 完整包及 r3.1 附件继续保留。离线升级只需目标清单与当前版本对应的增量，首次离线安装还需 r3 完整包，详见[安装指南](https://github.com/NEORUAA/HyperOS-AVD/blob/main/docs/installing.md)。手机与平板增量不能混用。

系统音频、相机高级算法、蓝牙、小米云服务与 Google 服务的兼容范围沿用 r3.1。
