# HyperOS 4.0.24.0 · v0.2.5 · Apple Silicon · r6.1

Release Tag：`v0.2.5-a17-hyperos4-hongkong-r6.1`。这是基于 Phone r6 的仅增量修复版，继续使用小米 18 Pro（hongkong）官方 **OS4.0.24.0.XFRCNXM / Android 17**。

## 本次修复

- 修复旋转后主屏窗口尺寸不正确，以及独立背屏窗口触控区域错位的问题。
- 更新至 **Core 19 / Apps 8**，按实际文件、ARM64 架构与硬件能力匹配兼容规则。
- 清理已由新版兼容模块接管的旧全局启动设置，保留原有迁移备份。
- 更新启动与显示默认脚本，继续保留手机的主屏、背屏与 AOD 配置。

## 安装与升级

需要 **Installer 1.3.1 或更新版本**。关闭目标 AVD，在安装器中选择 r6.1 即可。

已有完整 r6 文件时，只下载本次修复包。首次安装或缺少 r6 文件时，安装器会自动下载 r6 完整包，再应用修复并直接安装 r6.1。完整包只作为还原素材，不会先安装或启动旧版本。升级前仍会备份应用数据、磁盘覆盖层、加密密钥与配置。

本 Release 只提供增量分卷、`manifest.json` 和 `SHA256SUMS`。离线安装需同时准备 r6 完整包，具体目录结构见[安装指南](../installing.md)。

相机高级算法、蓝牙、小米云服务与 Google 服务的兼容范围沿用 r6。
